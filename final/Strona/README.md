# WebUI - Aplikacja Webowa

## 📄 index.html

Pełna, samodzielna aplikacja webowa systemu ticketowego.

### 🚀 Szybki Start

```bash
# Otwórz bezpośrednio w przeglądarce
open index.html

# LUB na webserverze
python3 -m http.server 8000
# http://localhost:8000
```
