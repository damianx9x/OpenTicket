# Desktop Application (Electron Wrapper)

Self-contained Electron application bundling:
- NestJS backend (SQLite database)
- Next.js frontend (static assets)
- Automatic backend process management
- IPC communication layer

## Architecture

```
┌─────────────────────────────────────┐
│  Electron Main Process (main.ts)    │
├─────────────────────────────────────┤
│ • Find & allocate free port         │
│ • Spawn NestJS backend process      │
│ • Create BrowserWindow with preload │
│ • Handle IPC requests               │
└─────────────────────────────────────┘
           │                  │
           │                  └──────────────┐
           │                                 │
    ┌──────▼──────────┐            ┌────────▼─────────────┐
    │ Backend Process  │            │ Frontend (Next.js)   │
    ├──────────────────┤            ├─────────────────────┤
    │• NestJS server   │◄──────────►│• React components   │
    │• Prisma + SQLite │            │• Static assets      │
    │• REST API        │            │• Auto-redirect      │
    │• Setup endpoints │            │• Setup wizard       │
    └──────────────────┘            └─────────────────────┘
```

## File Structure

```
desktop/
├── main.ts              # Electron main process (spawns backend, creates window)
├── preload.ts           # IPC bridge (exposes safe methods to frontend)
├── package.json         # Dependencies & build scripts
├── tsconfig.json        # TypeScript config
└── dist/                # Compiled JS (generated by npm run build)
```

## Key Features

### 1. Automatic Backend Management
- Finds free port in range 3000-3100
- Spawns NestJS backend as child process
- Waits for backend health check
- Kills backend on app exit

### 2. IPC Communication
Frontend can safely call:
```typescript
// Select folder via native dialog
const path = await window.electron.selectFolder();

// Get local IP for QR code generation
const ip = await window.electron.getLocalIp();

// Get app user data path
const appPath = await window.electron.getAppPath();
```

### 3. Database Management
- SQLite database stored in OS user data folder
- Auto-migrations via Prisma
- Config persistence

## Security

- **Renderer Isolation:** Preload script bridges safely via IPC
- **No Node Integration:** Frontend cannot access Node.js directly
- **Sandbox Mode:** Each window runs in sandbox
- **Context Isolation:** Separate contexts for main and renderer

## Troubleshooting

### App Won't Start
1. Check backend spawning: `node backend/dist/main.js`
2. Verify free port: `lsof -i :3000`
3. Check logs in console

### Frontend Missing
1. Build: `cd frontend && npm run build`
2. Output should be at `frontend/out/`

### Database Errors
1. Check SQLite: `ls ~/Library/Application\ Support/TicketSystem/`
2. Verify permissions: `chmod 755 ~/Library/Application\ Support/TicketSystem/`

## Development Tips

- Edit `desktop/main.ts` → run `npm run electron-dev`
- Frontend changes are auto-reloaded in dev mode
- Backend changes need restart (auto on dev mode)
- DevTools available (F12) in development mode

- Total startup: ~2-3 seconds
